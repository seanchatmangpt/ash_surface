# KNOWN_DIVERGENCES

Standing: UNVERIFIED

Register of divergences from `ash_typescript`, consumed by `mix ash_surface.parity`
(`lib/ash_surface/parity/register.ex`). Method prior art: smalt `KNOWN_DIVERGENCES.md`.

## Divergence law (operator, 2026-11-11)

A divergence is acceptable ONLY if ash_surface implements something better, witnessed by an
executed court. A row closes a capability in the gate only when ALL hold:

1. `better_because` is non-empty and names the concrete better behavior;
2. `court` is an existing repo-relative test file that executes the better behavior;
3. `receipt` is an existing receipt whose `Standing:` is `ALIVE` or `PASS`.

A row failing any of the three does NOT close its capability: the gate counts the cell
MISSING (exit 1) and prints the reason. Receipt-lint additionally requires every row's
receipt to carry a `Standing:` line in the closed vocabulary
`ALIVE | PARTIAL_ALIVE | PASS | BLOCKED | UNVERIFIED | PARTIAL`. A NON-GOAL court-map
entry is lawful only for README-declared non-goals: it must carry a `readme` field
quoting README.md verbatim.

## Adding a row

Add a `KD-nn` table row, then point a court-map entry
`{"status":"divergence","kd":"KD-nn"}` at it in `parity/court_map.json`. Run
`mix ash_surface.parity`; an unwitnessed row prints as MISSING with the failing clause.
